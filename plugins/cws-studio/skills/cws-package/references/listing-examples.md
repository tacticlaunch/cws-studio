# Listing examples — three full descriptions that passed moderation & ranked well

Use these as the structural and tonal target for Stage 2 full descriptions:
emoji-marked headers, multiple list types, an FAQ block, heavy but un-spammed
keyword use, short paragraphs.

## Example 2 — Youtube to Text

- Link: chromewebstore.google.com/detail/youtube-to-text/apnedodbofogffiagpekmbeflilkcbgf
- Name: `Youtube to Text`
- Short: `Youtube to Text: transcribe youtube video to text, generate accurate youtube transcript. Simplify convert youtube video to text.`

Structure highlights: a "Quick Start Tips" numbered list, a "🔟 reasons" list
using 1️⃣–🔟, ➤-bulleted benefit sections (Save Your Time, Boost Accessibility,
Enhance Video SEO, Organize and Archive), and a 📌/💡 FAQ. Keyword `youtube to
text` / `transcribe youtube video` / `convert youtube video to text` recur
throughout as whole phrases.

## Example 3 — Youtube repeat

- Link: chromewebstore.google.com/detail/youtube-repeat/jhkfddihpaahlogkaaljcfjlfpiomacl
- Name: `Youtube repeat`
- Short: `Let youtube repeat replay song in one click! Loop youtube video, listen song on repeat, and enjoy infinite loop for hours.`

Structure highlights: a "How to loop" numbered list, audience-segmented ➤ benefit
blocks (learners, musicians, dancers, cooks/DIY), and a ❓/💡 FAQ. Note how it
weaves many keyword variations — `loop youtube video`, `repeat youtube`, `youtube
repeater`, `looper youtube`, `play youtube video on repeat` — naturally into
sentences rather than stuffing the bare keyword.

## What to extract from these

1. Emoji-marked section header roughly every 1 paragraph.
2. At least 5 lists, of mixed types.
3. An FAQ block near the end (great for long-tail question keywords).
4. Short paragraphs, "air", no 4–5+ line walls.
5. The name keyword + variations woven in as whole phrases, frequently but below
   the spam threshold (verify in Turgenev — see `listing-copy.md`).
